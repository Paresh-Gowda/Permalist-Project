# 📋 Permalist — Task Management Application

## 🔗 Live Demo
[View Project](https://permalist-paresh.up.railway.app/)

Permalist is a full-stack task management application designed to help users create, organize, update, and manage their daily tasks through a simple and interactive interface. The application provides complete CRUD functionality, allowing users to add new tasks, edit existing ones, and delete completed or unnecessary tasks. With a clean and minimal design, Permalist focuses on delivering a straightforward and efficient task management experience.

The project is built using Node.js and Express.js for the backend, EJS for server-side rendering, and PostgreSQL for persistent data storage. It demonstrates important full-stack development concepts such as database integration, SQL queries, form handling, middleware, server-side rendering, and CRUD operations. Tasks are stored in a PostgreSQL database, ensuring that the data remains available even after refreshing or restarting the application.

Permalist was developed to strengthen practical full-stack development skills by combining a backend server, database, and dynamic user interface into a complete web application. The project is deployed on Railway, where the Express application and PostgreSQL database are hosted and connected using environment variables. GitHub is used for version control and continuous deployment, allowing updates pushed to the repository to be reflected in the live application.
